# report

Sends the result of your current task, or a question about it, to whoever assigned it (Juno). Call it once, when
you're done or stuck. Capped at {{report_length}} characters. Not needed for tasks the user typed in your pane.

## Parameters
- `text`: what you did, the result, where it is (branch, PR/MR, files), and what's left or what you're asking.
